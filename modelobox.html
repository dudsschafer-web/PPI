Modelo em Caixa - Model Box HTML

Os elementos HTML são estruturados em um moelo denominado "Modelbox", que refere-se a característica de um elemento por conter outros elementos, cada um possuindo uma etrutura interna, similar a ideia de uma caixa dentro da outra

Estrutura de um elemento HTML

Todos os elementos HTML possuem conteúdo, padding, borda e offset.
Sendo a região de conteúdo estruturada em três camadas:

  1. Background-color
  2. Background-image
  3. Content
