Por que a exibição fica assim?

A propriedade position: relative estabelece a área de referência para o posicionamento dos quadrados.
Já position: absolute permite posicionar cada elemento individualmente dentro dessa área,
utilizando as propriedades top, bottom, left e right. O quadrado magenta fica centralizado
devido à combinação de top: 50%, left: 50% e transform: translate(-50%, -50%).
