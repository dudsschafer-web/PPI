Sobre git

Sobre git discutimos o funcionamento do git, o que é o workcopy, stage, repositório. Os comandos git utilizados são listados abaixo

  • git init | cria um repositório git vazio .git
  • git status | exibe estado do rep.
  • git add | adiciona no stage
  • git commit -m "msg" | faz um commit
  • git log | lista os commits da branch(ramo) atual
  • git checkout branch | recupera wk a partir de um branch
