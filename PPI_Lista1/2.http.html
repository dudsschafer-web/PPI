Protocolo HTTP

O que é HTTP?

HTTP é um protocolo de comunicação entre cliente e servidor. Ele funciona através de requisições e respostas, sendo a base de toda navegação na internet.

Ciclo de Funcionamento

  • DNS resolve o endereço
  • TCP cria conexão
  • HTTP envia requisição
  • Servidor responde

Exemplo de Request

POST /login HTTP/1.1
Host: www.site.com
Connection: keep-alive
Content-Length: 35
Cache-Control: no-cache
User-Agent: Mozilla/5.0 (Windows NT 10.0)
Content-Type: application/x-www-form-urlencoded
Accept: text/html,application/json
Origin: https://www.site.com

usuario=eduarda&senha=123456

Exemplo de Response

HTTP/1.1 200 OK
Date: Mon, 20 Sep 2026 18:00:00 GMT
Server: Apache/2.4.1
Content-Type: text/html; charset=UTF-8
Content-Length: 98
Set-Cookie: sessionId=abc123
Cache-Control: no-cache

<html>
<body>
<h1>Login realizado com sucesso! <h1>
</body>
</html>

Métodos HTTP

  • GET → Buscar dados
  • POST → Enviar dados
  • PUT → Atualizar
  • DELETE → Remover

Status HTTP

  • 200 → OK
  • 404 → Não encontrado
  • 500 → Erro no servidor
