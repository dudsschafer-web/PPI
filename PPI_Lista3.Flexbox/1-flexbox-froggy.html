Explorando o Flexbox Froggy

Lista de atividades práticas - CSS Flexbox

Conhecendo o jogo

O Flexbox Froggy é uma plataforma interativa voltada ao aprendizado de CSS Flexbox. Ao longo de 24 desafios, o jogador deve utilizar diferentes propriedades de posicionamento para conduzir os sapos até as vitórias-régias correspondentes.

A proposta da atividade foi explorar os recursos de alinhamento, distribuição e organização de elementos, selecionando dois desafios para apresentar e explicar as soluções utilizadas.

Desafio 01 | Nível 13

O que precisava ser feito?

Neste nível, os sapos precisam ser reorganizados para alcançar suas respectivas vitórias-régias. Para isso, é necessário modificar a direção dos elementos e ajustar seu alinhamento dentro do lago.

CSS utilizado


            #pond { 
                display: flex;
                flex-direction: row-reverse;
                justify-content: center;
                align-items: flex-end;
            }

Entendendo as propriedades

A primeira alteração ocorre com flex-direction: row-reverse, responsável por inverter a ordem horizontal dos elementos. Dessa maneira, os sapos passam a ser distribuídos da direita para a esquerda.

Em seguida, a propriedade justify-content: center concentra os elementos no centro do eixo principal, mantendo o agrupamento horizontal.

Por último, align-items: flex-end desloca os sapos para a extremidade inferior do eixo transversal, completando o posicionamento necessário.

Desafio 02 | Nível 14

O que precisava ser feito?

Diferentemente do desafio anterior, o nível 14 trabalha com a ordem individual dos elementos. O objetivo é alterar a posição de um sapo sem modificar diretamente a organização dos demais.

CSS utilizado


                .yellow { 
                    order: 1; 
                }

Entendendo a propriedade

A propriedade order determina a posição visual de um elemento dentro de um container Flexbox.

Inicialmente, todos os elementos possuem o valor padrão 0. Ao atribuir o valor 1 ao sapo amarelo, ele passa a ser exibido depois dos outros sapos, que continuam com seus valores originais.

Portanto, não foi necessário alterar o HTML ou modificar a posição individual dos demais elementos, apenas estabelecer uma nova ordem para o sapo selecionado.

Resultado obtido

Considerações finais

Os desafios apresentados demonstram duas possibilidades de utilização do Flexbox. Enquanto o nível 13 exige a combinação de propriedades para controlar direção e alinhamento, o nível 14 permite compreender como modificar a ordem visual de um elemento específico.

A realização dos exercícios contribui para compreender como o CSS pode organizar componentes de uma página sem depender de posicionamentos manuais.
