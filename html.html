Origem do HTML

Linguagem de marcação criada por Tim Bernes Lee (1990) para compartilhamento de documento no CERN

Arquitetura Cliente Servidor da WEB

As tecnologias fundamentais que compoem a WEB são:

  • Arquitetura Cliente Servidor
  • HTTP - Hyper Text Transfer Protocol
  • HTML - Hyper Text Markup Language
  • Navegador Cliente -
  • Servidor Web

Ao longo dos anos a web evoluiu e nova tecnologia foram incorporadas como CSS e Javascript
